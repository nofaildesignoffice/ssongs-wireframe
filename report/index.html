상품등록이 곧 필터가 되게

필터 값을 따로 관리하지 않는다. 상품등록에서 이미 기입하는 옵션과 분류를 그대로 읽어, 옵션값이 하나 늘면 사용자 화면의 필터 칩도 하나 는다. 그 구조를 지금 데이터 위에 세울 수 있는지 실측했다.

01

구조 자체는 됩니다. 옵션명을 축으로, 옵션값을 칩으로 읽으면 상품등록에 값을 하나 추가할 때 필터 칩이 하나 늘어납니다. 별도 관리 대장도, 스킨 수정도 필요 없습니다.

단, 지금 데이터에 그대로 걸면 축 463개 · 칩 2,858개가 나옵니다. 「기종」이라는 한 축을 20가지 이름으로 부르고 있고, 「아이폰16」과 「아이폰 16」이 서로 다른 칩이 됩니다. 실제로 갈라져 있는 기종이 96개입니다.

모든 축을 옵션으로 옮길 수는 없습니다. 기종(케이스 92%)과 색상(카드지갑 70%)은 옵션에서 바로 나옵니다. 반면 형태·부착은 애초에 옵션이 아니라 분류에 있고(97~100%), 테마는 양쪽 다 부족합니다(31~38%). 축마다 소스를 지정해야 합니다.

§ 2

  4. 테마 값을 채운다쏭스 · 별도 판단유일하게 새로 정보를 넣어야 하는 축입니다. 11종안 기준. 이 단계를 건너뛰면 테마 축만 빼고 나머지는 그대로 갑니다.
