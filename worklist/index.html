핵심 — 운영몰을 안 건드리고 어떻게 만드나

카페24는 디자인·분류·상품이 각각 다르게 동작합니다. 그래서 격리 방법도 세 개가 따로 필요합니다. 공식 문서를 전수 확인한 결과, 세 개 모두 격리가 가능합니다.

1
디자인 — 새 스킨은 「대표 디자인」으로 지정하기 전까지 고객에게 안 보인다 확인됨

카페24는 디자인을 여러 개 보관할 수 있지만 실제 쇼핑몰에 적용되는 건 쇼핑몰당 1개(= 대표 디자인)뿐입니다. 새 스킨을 보관함에 아무리 만들고 고쳐도, 대표 디자인 버튼을 누르지 않으면 고객 화면은 그대로입니다. PC와 모바일은 각각 따로 대표 디자인을 가집니다.

2
상품분류 — 만드는 순간부터 「접근 불가」 상태로 만들 수 있다 확인됨

분류는 디자인과 달리 쇼핑몰 전체가 공유하는 데이터입니다. 그래서 「만들고 나서 숨기기」는 위험합니다. 그런데 카페24 API는 분류를 만들 때 use_display: "F"(표시안함) · use_main: "F"(메인 표시안함) · display_type: "F"(PC·모바일 모두 사용안함)를 생성 요청에 같이 넣을 수 있습니다. API 문서 원문: “표시안함 일 경우 해당 상품분류에 접근할 수 없다.” 즉 230개 분류는 처음부터 닫힌 상태로 태어납니다. 라이브 메뉴·검색·경로 어디에도 나타나지 않습니다.

3
상품 → 분류 연결 — 기존 분류를 지우지 않고 「추가」만 할 수 있다 확인됨

한 상품은 여러 분류에 동시에 들어갈 수 있습니다. 엑셀 업로드도 API도 추가 방식입니다. 카페24 공식 문서 원문: “엑셀에 입력하신 정보로 분류가 변경되는 것이 아닌 기존 할당된 분류는 유지되고 엑셀에 입력하신 분류가 추가돼요.” 기존 진열은 그대로 두고, 새로 만든 닫힌 분류에만 연결을 더합니다.

#위험왜 치명적인가사전 차단
1분류를 「만들고 나서 숨기기」 숨기기까지 몇 초라도 고객 메뉴에 230개가 쏟아진다 생성 요청에 use_display:"F"를 같이 보낸다. 생성 후 숨기기는 금지
2「분류수정 → 변경」 또는 「상품정보 일괄변경」을 누름 기존 분류가 전체 초기화되고 복구 불가. 상품이 쇼핑몰에서 사라진다 해당 메뉴를 작업자 권한에서 제거 · 분류는 API 또는 「추가」 모드만
3엑셀로 분류를 올리다 다른 열이 덮어써짐 가격·판매상태·옵션이 의도 없이 바뀐다. 재고가 초기화될 수도 있다 엑셀 대신 API 사용. 엑셀이 불가피하면 5개로 먼저 시험하고 전후 전수 대조
4분류를 지우고 다시 만듦 분류번호가 바뀌어 광고 랜딩·외부 링크·스킨에 박힌 번호가 전부 죽는다 삭제하지 않는다. 잘못 만든 분류는 닫은 채로 방치
5필터가 1페이지 상품만 보고 결과를 만든다 고객이 「없다」고 판단하고 떠난다. 조용히 매출이 빠진다 전체 상품 기준 결과 개수를 수동 집계와 대조. 페이지 넘김·정렬까지 검증
6PC만 전환하고 모바일을 잊음 대표 디자인은 PC·모바일이 따로다. 주력 고객이 깨진 화면을 본다 전환 체크리스트에 모바일을 별도 항목으로 두고, 실기기로 확인 후 완료 처리

#확인할 것어디서왜 필요한가
1지금 모바일 고객에게 나가는 스킨이 무엇인가 (반응형 1벌인가 PC/모바일 2벌인가) 디자인 → 디자인 보관함 → PC / 모바일 탭모바일 작업 범위가 2배 달라진다
2분류의 「접근 권한」 항목에 「특정 운영자만 이용 가능」이 있는가. 상위 분류에 걸면 하위까지 막히는가 상품 → 상품 분류 관리 → 아무 분류 클릭검증 창(Phase 7-1) 전체가 이 답에 달려 있다
3쇼핑 큐레이션을 이미 쓰고 있는가. 안 쓰면 월 비용이 얼마인가 상품 → 쇼핑 큐레이션필터 방식(6-1)과 「닫힌 분류가 새는지」가 여기에 걸린다
4현재 상품 검색 설정에 어떤 필터 조건이 켜져 있는가 쇼핑몰 설정 → 상품 설정 → 상품 정책 설정 → 상품 검색 설정 전 몰 공통 설정이라 전환 전에 건드리면 지금 고객 화면이 바뀐다
5멀티쇼핑몰이 이미 있는가. 추가 가능 여부와 비용 쇼핑몰 설정 → 채널 설정 → 카페24 채널 → 멀티쇼핑몰주문 리허설 환경 확보
6현재 주문서 유형 (일반 / 원터치 주문서) 주문 관련 설정주문서 편집 가능 범위가 달라진다
7설치된 앱 목록과 각 앱이 스킨에 스크립트를 넣는지 앱 → 설치된 앱스킨을 바꾸면 리뷰·검색·추적 앱이 따라올지 안 올지가 갈린다
8광고 추적 코드가 스킨·앱·설정 중 어디에 있는가 디자인 소스 / 마케팅 설정전환 후 전환 추적이 끊기면 광고비가 새어 나간다
9상품 해시태그가 이미 입력되어 있는가, 몇 개나 상품 → 상품 목록 → 아무 상품 → 표시설정필터 값의 재료. 비어 있으면 2,146개 입력 작업이 추가된다
10부운영자 권한을 메뉴 단위로 제한할 수 있는가 고객 → 운영자 관리사고를 사람이 아니라 시스템으로 막는다
